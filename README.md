**EcoSort AI** is a beginner-friendly, full-stack educational web application designed to help households, campuses, and communities sort waste responsibly. Developed for the **IBM SkillsBuild Masterclass 5**, this project aligns directly with **United Nations Sustainable Development Goal 12: Responsible Consumption and Production (Targets 12.5 & 12.8)**.

Users enter any common household item, scrap, or package (e.g., *plastic water bottle*, *banana peel*, *lithium battery*, *pizza box*, *old smartphone*). The system identifies its material characteristics, maps it to one of **eight canonical waste streams**, recommends color-coded bins, details rinsing and preparation steps, offers practical recycling/reuse ideas, and highlights vital safety precautions.

## 1. Key Features

* **Instant Multi-Stream Classification:** Categorizes queries into 8 standardized waste streams:
  1. *Wet or Organic Waste* (Green Bin)
  2. *Recyclable Paper and Cardboard* (Blue Bin)
  3. *Plastic Waste* (Yellow Bin)
  4. *Glass Waste* (Cyan Bin)
  5. *Metal Waste* (Grey Bin)
  6. *Electronic Waste (E-Waste)* (Purple Bin)
  7. *General or Non-Recyclable Waste* (Black Bin)
  8. *Hazardous or Special-Handling Waste* (Red Bin)
* **Dual-Engine Resiliency:** Powered by **Google Gemini API** (`@google/genai`) with structured JSON schema outputs; seamlessly falls back to a verified offline educational reference database (40+ items) if the API key is not configured or network access is offline.
* **Transparent Provenance:** Honest attribution clearly flags whether results were generated by live AI or retrieved from the offline reference knowledge base.
* **Private Local Activity Dashboard:** Computes real session statistics strictly from browser `localStorage` (total items classified, unique categories explored, most frequent category). Zero fabricated metrics.
* **Search History Management:** View recent classifications, re-inspect previous results with a single click, or clear history via an accessible native `<dialog>` modal.
* **Educational Recycling Guidelines:** Practical advice demystifying wishcycling, greasy pizza boxes, battery compaction hazards, and plastic resin codes (1–7).
* **Accessible & Responsive Design:** High-contrast WCAG AA compliant palette, dark mode / light mode toggle, keyboard navigation, and responsive mobile layouts.

## 8. Backend API Documentation

### `POST /api/classify`
Classifies a submitted waste item.
* **Rate Limit:** 30 requests per minute per IP.
* **Request Headers:** `Content-Type: application/json`
* **Request Body:**
  ```json
  {
    "item": "plastic water bottle"
  }
  ```
* **Success Response (200 OK):**
  ```json
  {
    "item": "Plastic Water / Beverage Bottle (PET #1)",
    "category": "Plastic Waste",
    "explanation": "Clear polyethylene terephthalate (PET #1) bottles are widely recyclable when clean.",
    "disposal_method": "Empty liquid completely, lightly rinse, crush to save space, replace cap tightly, and place in the dry recyclables / plastics bin (Yellow Bin).",
    "recycling_tip": "Re-screw the plastic cap onto the bottle after crushing; loose caps often slip through sorting screens at MRFs.",
    "safety_notes": "Rinse out any sugary residual fluids to prevent mold and insect attraction.",
    "confidence_level": "High",
    "is_fallback": false,
    "source": "Google Gemini AI (Live)",
    "local_rules_notice": "Local municipal waste collection rules vary by region. Please confirm with your local civic authority."
  }
  ```
* **Error Response (400 Bad Request):**
  ```json
  {
    "error": "Item name is too short. Please enter a descriptive waste item name (e.g., \"plastic bottle\", \"banana peel\")."
  }
  ```

### `GET /api/health`
System status and configuration check.
* **Response (200 OK):**
  ```json
  {
    "status": "healthy",
    "application": "EcoSort AI",
    "version": "1.0.0",
    "sdg_alignment": "UN SDG 12: Responsible Consumption and Production",
    "ai_service": {
      "provider": "Google Gemini",
      "model": "gemini-2.5-flash",
      "configured": true
    },
    "canonical_categories": 8,
    "timestamp": "2026-10-14T17:30:00.000Z"
  }
  ```

### `GET /api/categories`
Metadata on all 8 canonical waste categories, color schemes, and representative examples.

## 10. Render Deployment Guide

Deploying EcoSort AI to [Render](https://render.com) is free and takes under 3 minutes:

### Step 1: Push to GitHub
1. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of EcoSort AI"
   ```
2. Create a new repository on your GitHub account (e.g. `ecosort-ai`).
3. Push to your repository:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/ecosort-ai.git
   git branch -M main
   git push -u origin main
   ```

### Step 2: Create Web Service on Render
1. Log in to [dashboard.render.com](https://dashboard.render.com).
2. Click **New +** and select **Web Service**.
3. Connect your GitHub account and choose the `ecosort-ai` repository.
4. Fill in the settings:
   * **Name:** `ecosort-ai`
   * **Region:** Any region closest to you (e.g., Oregon, Frankfurt, Singapore)
   * **Branch:** `main`
   * **Root Directory:** *(leave blank for root)*
   * **Runtime:** `Node`
   * **Build Command:** `npm install`
   * **Start Command:** `npm start`
   * **Instance Type:** `Free`

### Step 3: Set Environment Variables
In the Render dashboard under **Environment Variables**, add:
* `GEMINI_API_KEY`: *(paste your Gemini API key)*
* `NODE_ENV`: `production`

### Step 4: Deploy
Click **Create Web Service**. Render will install dependencies, launch the Express server, and provide you with a live URL (e.g. `https://ecosort-ai.onrender.com`).

| **What makes EcoSort AI unique?** | It provides instant, multi-stream classification with preparation steps, upcycling ideas, and safety warnings without requiring registration or mobile app downloads. |

## 14. Ethical Disclaimer & Privacy Notice

* **Educational Guidance Only:** EcoSort AI is an educational guidance assistant and does not constitute official municipal waste collection or hazardous material authority. Local civic regulations and council directives always take precedence.
* **Privacy by Design:** Search history and activity statistics are stored strictly in the user's local browser (`localStorage`). No personal identifiable data, tracking cookies, or analytics beacons are collected.
