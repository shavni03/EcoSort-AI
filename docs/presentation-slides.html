Problem Statement Slide 02 / 08

The Household Waste Dilemma & "Wishcycling"

  • 2.24+ Billion Tonnes Generated Annually: Global municipal solid waste continues to surge, overwhelming landfill capacity worldwide.
  • The "Wishcycling" Disaster: Well-meaning citizens throw greasy pizza boxes, broken drinking glasses, or metallized chip bags into recycling bins. A single greasy carton can contaminate an entire pulping batch, diverting tons of paper to landfills.
  • Severe Hazardous Threats: Household lithium-ion batteries and toxic chemicals tossed in household bins ignite garbage collection trucks and leach heavy metals into groundwater.
  • Information Inaccessibility: Long municipal PDF brochures fail to deliver answers in the 3 seconds consumers take to discard items.
Source: World Bank What a Waste 2.0 & UNEP Problem Identification

AI Architecture Slide 04 / 08

Proposed AI Solution & Dual-Engine Design

  • Live Gemini Intelligence: Express backend securely interfaces with Google Gemini (@google/genai) using structured JSON schemas enforcing consistent, typed fields.
  • Resilient Offline Knowledge Base: If API credentials are absent or cloud services are unreachable, seamlessly matches against a curated reference database of 40+ verified items.
  • Transparent Provenance Tagging: Clearly distinguishes live AI classifications from offline reference results, maintaining academic honesty.
  • Privacy-First Edge Persistence: Search history and metrics stored strictly in the client's localStorage—zero database tracking or data harvesting.
Security: Zero API Key Exposure to Browser Architecture Overview
